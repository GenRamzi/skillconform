# Roadmap

## v0.1 — Foundation

- Agent Skills frontmatter and structure validation.
- Workspace discovery.
- Deterministic security rules.
- Pretty, JSON, and SARIF output.
- Policy regression tests.
- GitHub Action and reusable TypeScript API.

## v0.2 — Portability

- Client compatibility profiles.
- Configurable rule severities and documented suppressions.
- Shell and PowerShell command-aware analysis.
- JSON Schema for `skillconform.yaml`.
- Faster incremental scans for large repositories.

## v0.3 — Supply chain

- Reproducible skill archives.
- Checksums and provenance manifests.
- Dependency and remote-resource inventory.
- Optional SBOM output for bundled scripts.

## v1.0 — Stable policy platform

- Stable rule and configuration contracts.
- Versioned migration tooling.
- Plugin and editor integrations.
- Community-maintained compatibility test suite.

Roadmap items are proposals, not delivery commitments. Open an issue before implementing a large feature so the design can be discussed first.
